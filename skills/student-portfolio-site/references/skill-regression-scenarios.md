# Skill Regression Scenarios

Run these four scenario reviews whenever this Skill or its distribution package changes. A response may vary in wording; it passes when it follows the required user journey without inventing facts or forcing unnecessary steps.

| Scenario | Input | Expected behavior |
| --- | --- | --- |
| Complete material, no style preference | A student uploads a resume and asks for a portfolio. | Identify role, evidence, and public boundary; present three tailored directions plus the fourth upload option; obtain confirmation before the visual build. |
| No resume, no project, no direction | “我什么都没准备，也没有项目，不知道投什么。” | Ask one easy question at a time; surface honest course, club, writing, part-time, or prototype evidence; never invent an internship or metric; do not block on a resume. |
| Reference-led taste | The student shares two screenshots and one public application link, then chooses the fourth option. | Respect privacy and observable limits; produce a reference-to-decision map; apply design principles without copying brands, assets, text, or full layouts; request a lightweight brief confirmation. |
| Existing-site maintenance | “把我的作品页一个失效图片修好，其他别动。” | Diagnose the asset and preserve existing routes, links, and design. Do not invoke the aesthetic-choice gate for this non-visual maintenance task. |
