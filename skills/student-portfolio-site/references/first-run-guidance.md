# First-Run Guidance for WorkBuddy Users

Use this guide when the student is starting a new portfolio from little or no prepared material, or explicitly asks to be led through the process. The goal is a conversation that moves forward with one easy response at a time—not a checklist the student has to manage.

## The only starter a user needs

If someone needs a sentence to begin, give them this one:

```text
请使用 student-portfolio-site，带我做一个用于秋招的个人作品网站。我不知道怎么开始，请按你的流程一步一步问我，先不要直接做页面。
```

After that message, lead the rest of the process yourself. Do not ask the user to paste a second, third, or fourth “prompt” unless they specifically want an advanced reusable template.

## Conversation shape

### 1. Welcome and collect the easiest available material

Open in a natural, reassuring way. State the three phases in one sentence: first sort facts and public boundaries, then choose a visual direction, then make a local draft.

Ask only this first question:

```text
你现在手边有什么？
① 简历或项目材料：直接上传就行；
② 只有零散经历：我按格式问你；
③ 还没整理：先告诉我想投什么方向；
方向也还没想好，直接回我“还没想好”就行。
```

If the user uploads material, inspect it before asking more. If they choose ② or ③, continue rather than telling them to prepare a resume first. Before they upload, add one light reminder: phone numbers, addresses, identity information, company-internal material, and anything with uncertain public status can be redacted or left out for now.

### 2. Fallback intake when there is no resume

Offer this compact form and accept incomplete answers:

```text
想投的方向：
我最想放的 2—3 段经历/项目：
每段里我具体做了什么：
可以公开的内容：
不想公开或需要脱敏的内容：
希望别人第一眼感受到什么：
```

Ask follow-ups only for facts that change the site. For example, if a project lacks a result, ask what the concrete output or learning was; do not pressure the user to invent an impact number.

If the user says “我没有项目” or “想不出来”, do not stop there. Remind them that course work, clubs, competitions, part-time work, writing, self-initiated experiments, and small prototypes can all be presented honestly. If they still cannot think of one, accept “想不出来” and ask one gentle question at a time to surface a real starting point.

### 3. Confirm the material boundary before discussing visuals

Briefly restate what is known, what should stay private, and any important `[待我确认]` gaps. Then say what will be shown first on the website. Keep it short enough for the student to correct.

If nothing substantive is available yet, make a narrow, honest starter site around direction, course work, a prototype, writing, or a learning project. Never suggest fabricated internships, metrics, testimonials, or corporate work.

### 4. Make the aesthetic choice easy

Use the exact format and fast path in [aesthetic-interaction-contract.md](aesthetic-interaction-contract.md). Always keep the fourth option—“我的审美比你牛，我来上传”—available.

### 5. Confirm once, then create the local first draft

Summarize the selected direction in a short actionable brief. After the student confirms—or replies “就按推荐做”—create the site. Use confirmed materials only; mark only unavoidable gaps as `[待我确认]`.

Deliver a local preview and say three things plainly:

1. what was created and how to open it;
2. which content is still awaiting confirmation;
3. the easiest next choice: revise copy, replace material, or review for public sharing.

When the host allows it, choose a clearly named local project folder yourself and tell the student exactly where it is. Only ask where to save if the host truly cannot proceed without that choice. Do not deploy, publish, or add newly sensitive contact information without an explicit request and confirmation.
